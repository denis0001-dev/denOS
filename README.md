# denOS
denOS - это новая операционная система, которая скоро 
заменит Windows, Linux и macOS.
## Что сейчас есть
- Текст на экране
- Поддержка клавиатуры
- Ввод команд
### Какие команды сейчас доступны
| Команда   | Описание                                              |
|-----------|-------------------------------------------------------|
| shutdown  | Завершить работу ядра                                 |
| version   | Показать информацию о версии                          |
| changelog | История изменений                                     |
| help      | Показать список команд                                |
| test      | Тестировать функции (команда будет постоянно менятся) |
Больше команд будут добавлены позже.
## Что планируется
- Мышка
- Функция printf
- Поддержка прерываний
- Обработка прерываний
- Кастомная файловая система denFS
## Над чем я уже работаю
- Конвертация чисел в строки
